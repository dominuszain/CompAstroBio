# BLS transit detection

This folder contains `bls_transit_detection.ipynb`, the full Box Least Squares
analysis on the 1000-light-curve dataset. The notebook fits a box-shaped transit
model over a grid of trial periods and records the best period and detection
score for each light curve.

For a shorter run on the included 100-light-curve sample, use
[`../demo_bls.ipynb`](../demo_bls.ipynb).
