# ResNet-1D transit detection

This folder contains `cnn_resnet_transit.ipynb`, the full ResNet-1D analysis on
the 1000-light-curve dataset. The notebook trains the network on phase-folded
light curves and compares its classifications with the BLS results.

For a shorter run on the included 100-light-curve sample, use
[`../demo_cnn.ipynb`](../demo_cnn.ipynb).
