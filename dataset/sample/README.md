# Sample dataset

This folder contains 100 PSLS-simulated PLATO light curves: 50 with transits
(`label1`) and 50 without (`label0`). Each `run_*.dat.gz` file holds a time
series, and `metadata.csv.gz` lists the simulation parameters for each run.

The full 1000-light-curve dataset is on Zenodo:
[https://doi.org/10.5281/zenodo.19715574](https://doi.org/10.5281/zenodo.19715574).
